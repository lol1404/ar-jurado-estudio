# A.R. Jurado - Photography Studio Website

This project is a website for the photography studio A.R. Jurado, based in Seville, Spain. The website is designed to showcase their work, services, and client testimonials.

## Sections

The website includes the following sections:

- **Inicio / Bienvenida:** A brief introduction to the studio and its philosophy.
- **Servicios:** An overview of the different types of photography sessions offered.
- **Testimonios:** Positive feedback from satisfied clients.
- **Galería:** A showcase of the studio's creative and original work, with a collage-style layout.
- **Contacto / Reserva:** A call to action for booking a session, including contact information, an interactive map, and a link to their Instagram profile.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

To view the website, simply open the `index.html` file in your web browser.
